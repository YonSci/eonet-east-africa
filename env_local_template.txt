# EmailJS configuration for browser-based email delivery
# Get these from https://www.emailjs.com (free account)
#
# 1. Dashboard -> Email Services -> Add Service -> Gmail -> Connect
# 2. Dashboard -> Email Templates -> Create Template (see TEMPLATE GUIDE below)
# 3. Account -> API Keys -> Public Key
#
# TEMPLATE GUIDE -- paste these into EmailJS template editor:
#
# Template 1 (confirmation):
#   Name: NHMT-EA Confirmation
#   Subject: You are subscribed to NHMT-EA alerts
#   Body (HTML):
#     <h2>NHMT-EA Alert Subscription Confirmed</h2>
#     <p>Hi {{to_name}},</p>
#     <p>You are now subscribed to receive natural event alerts for:</p>
#     <p><strong>Categories:</strong> {{categories}}</p>
#     <p><strong>Countries:</strong> {{countries}}</p>
#     <p>You will receive an email when new events matching your filters
#     are detected during the 15-minute data refresh.</p>
#     <p>To unsubscribe, visit the About page of the dashboard and
#     remove your subscription from the list.</p>
#     <p>-- NHMT-EA Team</p>
#   To email: {{to_email}}
#   From name: NHMT-EA Natural Hazard Monitoring & Tracking
#
# Template 2 (alert):
#   Name: NHMT-EA Event Alert
#   Subject: NHMT-EA Alert: {{event_count}} new {{categories}} event(s) detected

#     <h2>Natural Event Alert -- {{event_count}} new event(s)</h2>
